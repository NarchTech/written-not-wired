# Written ≠ Wired: Hunting Fake-Green in Agent Systems

**Prof. Dr. Mustafa Melikoğlu · Yağız Deniz Altınbaş · Tayfun Tanrıöver**

A green light is a claim, not a fact. This preprint names four species of **fake-green** — the defense that
was written but never wired in, the process that exists but isn't running, the exit code 0 that reports done
without doing, and the check that measured the wrong surface — and documents four measured incidents from a
working AI-agent fleet, July–August 2026.

The argument is narrow and, we think, newly urgent: mutation testing, chaos engineering and dead-code
detection are mature disciplines, but they now have to be turned on **generated defenses** — the guards an
agent writes and reports as done — because that is where fake-green is produced fastest.

## The one-paragraph version

Fake-green is worse than red, because red interrupts you and fake-green compounds. The cure is
counterfactual verification: every protection ships with a test that removes or mutates it and watches the
failure happen; verification reads the live surface, never the note; "could not measure" is a stop, not a
pass. **A protection you have never watched fail has never been tested.**
